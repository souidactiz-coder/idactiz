IDACTIZ — Cartão Digital Tech Oficial (com contador de visitas)

ARQUIVO PRINCIPAL: index.html

PUBLICAR NO GITHUB PAGES
1. Faça backup do index.html atual do repositório idactiz.
2. Envie index.html à raiz do repositório souidactiz-coder/idactiz.
3. Aguarde a publicação em https://souidactiz-coder.github.io/idactiz/.

CONTADOR DE VISITAS
- Exibido discretamente no rodapé do cartão.
- Utiliza o serviço externo gratuito VisitorBadgeReloaded (vbr.nathanchung.dev).
- Sem senha nem chave de API. A imagem do contador carrega somente na página publicada no endereço acima.
- Ao abrir index.html no computador, o contador permanece inativo e não soma testes.
- O valor começa a ser contabilizado quando o novo HTML é publicado: não recupera acessos anteriores.
- São contabilizados carregamentos (hits), e não visitantes únicos. Bots/recarregamentos podem alterar o total.
- Depende da disponibilidade do fornecedor; em caso de falha, aparece "Visitas indisponíveis no momento".
- O navegador contata um serviço terceiro, que pode receber dados normais de uma requisição web,
  como o endereço IP. A imagem utiliza referrerpolicy=no-referrer para não repassar a URL da página.
- O ID do contador não deve ser trocado quando atualizar o cartão, para preservar o histórico.

RECURSOS PRESERVADOS
- CSS, JS e identidade visual da IDACTIZ estão no HTML, sem precisar de instalações.
- Botões de WhatsApp, telefone, Instagram, e-mail, salvar vCard e compartilhar.
- Detalhes de serviços e lista de projetos recolhida inicialmente.
- O HTML e o ZIP estão prontos para GitHub Pages; o site público não foi alterado automaticamente.
